# IP-SAKTI Sahayak (Legal Platform)

> **Grounded Botanical Intelligence for Sovereign IP**  
> Evidence-grounded IP & regulatory navigation for Ayurvedic innovation. Navigate classification, patentability §3(p), TKDL prior-art, and ABS biological diversity clearance in one calm, guided workflow.

---

## 🌟 Overview

IP-SAKTI Sahayak is an end-to-end legal intelligence platform built for AYUSH practitioners, biotech legal counsel, and traditional knowledge administrators. It streamlines Ayurvedic patent search, Traditional Knowledge Digital Library (TKDL) clearance, and Access and Benefit Sharing (ABS) compliance under India's Biological Diversity Act.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)

### Run Locally
```bash
# Start the local development server
npm start

# Or run directly with Node
node server.js
```

Then open your browser to **[http://localhost:3000](http://localhost:3000)**.

Alternatively, you can simply open `index.html` directly in any modern web browser.

## 🏛️ Platform Architecture & Routes

The entire application runs as a responsive Single-Page Application (SPA) with client-side hash routing:

| Route | Page | Purpose |
|---|---|---|
| `#landing` | **Calm Kinetic Landing Page** | Hero overview, feature cards, sovereign framework highlights |
| `#roles` | **Role Selection Gate** | Switch between Researcher, Facilitator, and Admin personas |
| `#dossiers` | **My Dossiers** | Active dossiers, clearance statuses, risk levels, empty-state simulation |
| `#tkdl` | **TKDL Prior Art Search** | Multi-jurisdiction search across AYUSH, EPO, USPTO, and WIPO |
| `#abs` | **ABS Biodiversity Check** | Form 1 clearance, NBA statutory gates, state board requirements |
| `#escalation` | **Escalation Confirmation** | High-risk flagging and statutory specialist review dispatch |
| `#ask-ai` | **Ask AI Assistant** | Grounded legal co-pilot referencing TKDL and Biodiversity rules |
| `#intake-2` | **Product Intake: Ingredients** | Dynamic ingredient formulation builder with botanical taxonomies |
| `#intake-3` | **Product Intake: Claims** | Core patent claim analysis and interactive keyword hypothesis chips |
| `#intake-4` | **Product Intake: Bio-Source** | Biological material provenance, state of origin, and vendor vetting |
| `#intake-5` | **Product Intake: Market Review** | Multi-territory patent jurisdiction review (IN, US, EP, JP, GCC) |
| `#admin` | **Admin Overview** | System metrics, active users, corpus health, fast action triggers |
| `#corpus` | **Source Corpus Management** | Manage Ayurvedic treatises, patent databases, and legal gazettes |
| `#source-edit` | **Source Detail & Edit** | Metadata editor, parsing rules, and sync schedule configuration |
| `#users` | **User & Role Management** | Manage access privileges, department credentials, and API keys |
| `#audit` | **Audit Log** | Immutable legal activity logs, timestamp tracking, and export |
